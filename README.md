# Bank Management System

A python project.

## Features
- Create account and PIN login
- Deposit, withdraw and transfer money
- Balance and transaction history
- Update customer profile
- Close account
- Search accounts
- Admin panel and bank statistics
- JSON file storage

## Run

```bash
python bank_management.py
```

Windows alternative:

```bash
py bank_management.py
```
